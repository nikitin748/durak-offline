# Дурак офлайн

Android-клон «Дурак онлайн», который работает без интернета: 2–6 игроков на разных телефонах по Wi‑Fi/точке доступа, боты для пустых мест.

- `engine/` — правила (подкидной, переводной), боты, тесты (чистый Kotlin/JVM)
- `app/` — Android-приложение (Jetpack Compose)

Тесты движка: `gradle test -PengineOnly`
